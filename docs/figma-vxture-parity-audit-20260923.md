# Figma / `@vxture/design` Parity Audit

审计日期：2026-09-23  
Figma 文件：`Vxture-Design-System` (`Fxrb8llzofI9MuNqQvTSEJ`)  
源码范围：`@vxture/design-ui`、`@vxture/design-system`、`@vxture/design-tokens`

## 1. 审计范围与结论

- 源码运行时导出：`@vxture/design-ui` 255 个，另有 `@vxture/design-tokens` 7 个运行时导出。
- 源码视觉组件文件：base 52 个 TSX 文件、composite 31 个、layout 7 个、templates 5 个；`@vxture/design-system` shell 6 个。
- Figma 当前页面节点：9 个，去重后为 `01 · Foundations`、`02 · Icons`、`03 · Typography`、`04 · Components`、`05 · Component Groups`、`06 · Templates`、`07 · Code Sync`、`90 · Sandbox` 共 8 个名称；`90 · Sandbox` 出现两个页面节点。
- 台账预期的 `00 · Cover` 当前不存在；`90 · Sandbox` 出现两次的历史记录与当前页面实际不一致，应单独修正。
- Figma `02 · Icons` 有 149 个图标组件集。源码 `iconRegistry.ts` 的语义注册明显多于 149 个，不能判定为完全一致；需要按名称映射清理。
- Figma `04 · Components` 当前有 266 个组件/组件集根节点，其中包含 current、Legacy、内部 helper 和未公开辅助资产；不能把 266 个全部当作 `@vxture/design` 公共组件。
- Figma `05 · Component Groups` 的 41 个根组件是产品/业务组合，不属于 `@vxture/design` 公共包；这与源码 composite index 的“零业务、不带产品专名”边界一致。
- Figma `06 · Templates` 保留的是旧版页面装配；源码当前模板已在 `04 · Components / A17 · Templates` 建模，二者不是同一套资产。

结论：**基础组件与当前组合组件的主干已经对齐，但 Figma 仍是“当前源码组件 + 内部 helper + Legacy + 产品业务组 + 历史模板”的混合文件，不能直接视为一份与 `@vxture/design` 一致的发布库。**

## 4. 源码存在、Figma 没有独立公共视觉资产的导出

这些不是缺失实现，而是运行时结构、Provider、slot 子件或纯布局 API，不能按“每个 export 一个 Figma component”补齐：

- Radix 结构件：`Dialog*`、`AlertDialog*`、`DropdownMenu*` 的 Root/Portal/Trigger/Group、`ContextMenu*` 的 Root/Portal/Trigger、`Popover*`、`Tooltip*`、`TabsContent`、`Collapsible*`。
- 视觉子件：`AvatarImage`、`AvatarFallback`、`AvatarSilhouette`、`CardHeader`、`CardFooter`、`CardTitle`、`CardDescription`、`TableCell`、`TableRow`、`BreadcrumbLink`、`BreadcrumbPage`、`BreadcrumbSeparator`、`InputGroupAddon`、`InputGroupInput`、`InputOTPGroup`、`InputOTPSeparator`。
- 运行时/工具：`FullscreenProvider`、`ToastProvider`、`useToast`、`useBreakpoint`、`useFullscreen`、`cn`、`buttonVariants`、`toggleVariants`、`iconDictionary` 及 token 常量。
- 源码组合但当前 Figma 无公共根：`FilterPanel` / `FilterPanelTrigger`。源码已将 FilterPopover 作为当前设计表达，FilterPanel 应保留为迁移/兼容 API，而不是重新建 Figma 资产。
- `AspectRatio` 是无视觉样式的布局工具，源码没有对应 Figma 视觉组件是正确的。

## 5. Figma 存在但不属于 `@vxture/design` 公共 API 的资产

### Legacy

Figma A02-A15、A14 等仍有大量 `Legacy ·` 组件集：Legacy Input、Textarea、FormField、Select、Search、NumberInput、DatePicker、Upload、Checkbox、Radio、Toggle、Slider、Rate、SegmentedControl、Badge、Status、Alert、Toast、Notification、Message、Tooltip、MenuItem、Popover、Dropdown、Modal、Drawer、Avatar、OrgLogo、Tabs、Breadcrumb、PageItem、StepItem、TableRow 等。

它们的存在用于历史实例迁移或兼容，不应作为当前 `@vxture/design` Library 发布。当前 audit 中 38 个 `CHANGED` 根资产也主要集中在这些 Legacy/历史 Component Group 节点。

### Internal/private helpers

Figma 当前 helper 命名包括：`__Shell / Slot`、`__ShellPanel / Slot`、`_Field / Label`、`_Field / Description`、`_Field / Error`、`_InputGroup / Addon`、`_Combobox / Trigger`、`_Combobox / Panel`、`_Table / Cell`、`_Table / Row`、`__ActionMenu / DangerItem`、`__ViewModeSwitch / Item`、`__FilterPopover / Panel`、`_Layout / Slot`、`_Layout / SplitBody`、`__DashboardTemplate / Entries`、Rating 的 Star/Value helpers 等。

这些 helper 可以作为已发布公共组件的依赖，但不应单独出现在消费者的组件选择列表。发布报错很可能来自“已发布父组件引用未发布 helper/子组件”的依赖链。

### Component Groups / 业务资产

05 页 41 个根组件全部是产品业务组合，典型包括：

- X00：`tagGroup`、`Statistical_period`
- X01 Header：`Header_Tenant_Select`、`Header_components_*`、`HeaderToolbar`、`AiAgentIcon`、`Header Brand Mark`
- X02 Sidebar：`NavItem`、`sidebar_components_*`、`Sidebar_Nav_*`
- X03 Identity：`UserInfo_Header`、`TenantInfo_Title`、`AuthenticationStatus`、`TencentClass`
- X04 Data：`Tenant_Balance`、`Tenant_Storage`、`Tenant_Invoice`、`Tenant_AiCredits`、`Group_Name`、`User_Honor`
- X05 Actions：`User_*`、`Tenant_*`、`Divider_Line`
- X06-X08：`PageHeader_*`、`PageCard_C1`、Table/FilterBar/Pagination 组装

这些资产依赖公共 Button、Input、StatusBadge、Table 等，但它们本身带有 User/Tenant/Account/Authentication 等业务语义；源码 composite index 明确规定这类资产不进公共包，应归产品/domain-ui。

## 6. `06 · Templates` 与当前源码的差异

Figma 06 页当前根组件为：`PageTemplate`、`sidebar-nav-collapsed`、`sidebar-nav-expanded`、`Header_product`、`Header_console`、`Header_admin`、`Header_website`。

源码当前模板为：`ListPageTemplate`、`DetailPageTemplate`、`FormPageTemplate`、`DashboardTemplate`、`ResultPageTemplate`。它们已在 Figma 04 的 A17 建立对应资产。

因此 06 页不是“源码模板缺失”，而是历史页面装配未迁移/未删除。建议保留为迁移参考页，并明确页名为 `Legacy · Templates`，不作为当前 Library 发布入口。

## 7. Foundations / tokens 差异

- 源码 token manifest：608 个 token（247 primitive、361 semantic）。
- Figma 变量：1,323 个，分布在 15 个 collection。
- 当前 Figma 额外 collection：`vx-Component`、`vx-Shape`、`vx-Depth`、`vx-Motion`、`vx-Layout`、`vx-Element`、`vx-Motion-Primitive`、`vx-Shadow-Primitive`、`vx-Radius-Primitive`。
- 164 个未发布变量全部来自隐藏 primitive collection：Color 109、Spacing 25、Typography 30；这是预期的隐藏基础层，不应作为发布失败的主因。
- 需要继续核对的是真正面向消费者的 semantic 变量是否都来自源码 CSS，而不是 Figma 独有的组件层变量。特别是 `vx-Component` 等集合，如果没有对应 CSS/TS source，应标记为 Figma-only 或迁回 token source。

## 8. 当前发布状态与建议

最近一次发布尝试后状态为：

- 组件：1,929 个节点中 `CURRENT=180`、`CHANGED=38`、`UNPUBLISHED=1,711`。
- 变量：1,323 个中 `CURRENT=1,159`、`CHANGED=0`、`UNPUBLISHED=164`。
- 已发布的 Shell/组件集仍包含未发布的 nested master，例如 `__Shell / Slot`、Button、Icon、Avatar、StatusBadge、Overlay helpers；应按依赖顺序处理。
- Legacy/业务组件不应为了清空 publish list 而强行发布。

建议发布批次：

1. 发布 Foundations 中面向消费者的 semantic collections；保持 primitive collections hidden。
2. 发布公共 Icon component sets 与公共 base atoms。
3. 发布公共 composite、layout、template 和 Shell 结构；确认内部 helper 的发布策略后再发布父组件。
4. 排除所有 `Legacy ·`、`.`、`_`、`__` 资产以及 05/06/07 页历史/业务资产。
5. 发布后重新检查 `CURRENT`，再开始 Code Connect；不要用“所有节点 CURRENT”作为完成标准，完成标准应是“所有源码公共视觉根 CURRENT，Legacy/private 仍明确排除”。
